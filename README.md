# Dashboard de Hematología Clínica

Herramienta de estudio para el curso de Hematología Clínica — Universidad Santo Tomás · Tecnología Médica.

## Acceso

URL del dashboard publicado: https://USUARIO.github.io/hematologia-dashboard/

(reemplazar `USUARIO` por el usuario de GitHub real)

## Contenido

- 4 unidades: Anemias y Trastornos Hemorrágicos · Patología Leucocitaria · Neoplasias Mieloproliferativas · Laboratorio
- Quiz interactivo: 50 preguntas con feedback inmediato
- Flashcards: 48 tarjetas por unidad
- Árbol diagnóstico de anemias
- Comparador de patologías
- Calculadora de índices hematológicos
- Biblioteca con 16 documentos indexados
- Notas personales por unidad (autosave local)
- Modo oscuro/claro · responsive móvil

## Stack

HTML + CSS + JavaScript vanilla. Sin frameworks. Todo el progreso se guarda en `localStorage` del navegador.

## Uso local

Abrir `index.html` con un servidor HTTP local:

```powershell
python -m http.server 5500
```

Luego visitar http://localhost:5500
